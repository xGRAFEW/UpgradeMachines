# UpgradeMachines

ปลั๊กอิน **Paper** (Minecraft Java) สำหรับอัพเกรด **เตาเผาทุกชนิด (Furnace / Blast Furnace / Smoker), Hopper, Dispenser, Dropper และ Crafter**

## หลักการออกแบบ
- ทุกการอัพเกรด **เพิ่มแค่ "อัตรา" เท่านั้น** — ไม่มีไอเทมใหม่ ไม่มีสูตรใหม่ ไม่เปลี่ยนกลไกวานิลลาอื่น ๆ
  - เตาเผา → **เผาได้ครั้งละหลายชิ้น** (batch smelting) ระดับ 1-4 = 8/16/24/32 ชิ้นต่อ 1 รอบเผา — เวลาต่อรอบและเชื้อเพลิงที่ใช้เท่าวานิลลาเดิม ใช้แค่วัตถุดิบเพิ่มตามจำนวนที่เผา (ยิ่งอัพเกรดสูงยิ่งคุ้มเชื้อเพลิง)
  - Hopper → ส่งไอเทมได้มากขึ้นต่อรอบ (ปกติ 1 ชิ้น/8 ticks)
  - Dispenser / Dropper → ยิง/ดันไอเทมออกมากขึ้นต่อการทำงาน 1 ครั้ง (สองบล็อกนี้ใช้กลไกเดียวกัน แค่ตั้งค่าคนละชุด)
  - Crafter → คราฟซ้ำได้มากขึ้นต่อการทริกเกอร์ 1 ครั้ง
- ระดับอัพเกรดถูกเก็บไว้ **บนตัวบล็อกโดยตรง** ผ่าน PersistentDataContainer (ไม่มีดาต้าเบสภายนอก ย้าย/โหลดพร้อมโลกเสมอ) และ**ติดไปกับไอเทมด้วยเมื่อทุบบล็อก** (ดูหัวข้อ "ทุบ/วางบล็อกที่อัพเกรดแล้ว")

## ความต้องการ
- เซิร์ฟเวอร์ **Purpur/Paper 26.2+** (ทดสอบจริงบน Purpur 26.2-stable) — ไม่ใช่ Spigot ธรรมดา เพราะใช้ `CrafterCraftEvent`
- Java 25+ (ตรงกับ runtime ที่ Purpur 26.2/26.3 ต้องการ)
- Maven (สำหรับ build)
- **Vault** (ทางเลือก) — ติดตั้งเพิ่มถ้าต้องการเก็บราคาอัพเกรดเป็น "เงิน" (ต้องมีปลั๊กอินระบบเงินอย่าง EssentialsX ด้วย) ถ้าไม่ติดตั้ง Vault ราคาส่วนที่เป็นเงินจะถูกข้ามอัตโนมัติ ไม่กระทบการทำงานส่วนอื่น

## วิธี build
```bash
mvn clean package
```
ไฟล์ jar จะอยู่ที่ `target/upgrademachines-1.0.0.jar` — เอาไปวางในโฟลเดอร์ `plugins/` ของเซิร์ฟเวอร์แล้วรีสตาร์ท

## วิธีใช้งานในเกม
| คำสั่ง | คำอธิบาย | สิทธิ์ |
|---|---|---|
| `/upgrade info` | ดูระดับอัพเกรดของบล็อกที่กำลังมอง + ราคาระดับถัดไป | ทุกคน |
| `/upgrade reload` | โหลดค่า config.yml ใหม่ | `upgrademachine.admin` |

**การอัพเกรดบล็อก:** **Shift + คลิกขวา** ที่เตาเผา/ฮอปเปอร์/ดิสเพนเซอร์/ดรอปเปอร์/คราฟเตอร์ → เปิด**กล่องยืนยันอัพเกรด** โดย**ชื่อกล่อง (แถบหัวกล่อง) จะแสดงผลที่จะได้และราคาไปเลยทันทีที่เปิด** (เช่น `เตาเผา เผาทีละ: 16 ชิ้น - 500`) และในช่องไอเทมกลางก็มี lore แจกแจงระดับปัจจุบัน → ระดับใหม่, ผล, ราคาซ้ำอีกรอบแบบละเอียด พร้อมปุ่ม **ยืนยันอัพเกรด** (หักเงิน/ไอเทมแล้วอัพเกรดจริง) กับ **ยกเลิกการอัพเกรด** (ปิดกล่องเฉย ๆ ไม่เสียอะไร) ไม่ต้องใช้ไม้หรือไอเทมพิเศษใด ๆ — ถืออะไรอยู่ก็เปิดกล่องได้ ต้องมีสิทธิ์ `upgrademachine.use` (ค่าเริ่มต้นเปิดให้ทุกคน)
คลิกขวาแบบไม่กด Shift ยังเปิด/ใช้งานบล็อกตามปกติแบบวานิลลาเหมือนเดิม ไม่มีการลดระดับ (downgrade) ในปลั๊กอินนี้

## ทุบ/วางบล็อกที่อัพเกรดแล้ว
ทุบบล็อกที่มีระดับอัพเกรด (Lv. ≥ 1) จะได้ไอเทมที่**เปลี่ยนชื่อ + lore** ให้เห็นค่าประสิทธิภาพจริงทันที เช่น
```
ดรอปเปอร์ → Lv.3
ดรอปทีละ: 4 ชิ้น
```
ระดับอัพเกรดถูกฝังไว้ในตัวไอเทมเอง (ไม่ใช่แค่ข้อความ) เอาไปวางที่ไหนก็ได้ — บล็อกใหม่จะได้ระดับเดิมกลับคืนทันที (ถ้า config ปัจจุบันลด max-level ลงจนต่ำกว่าระดับเดิม ระดับที่ได้จะถูก clamp ลงมาที่ max ใหม่) บล็อกที่ยังไม่เคยอัพเกรด (Lv.0) ทุบแล้วดรอปเป็นไอเทมปกติแบบวานิลลา ไม่มีการเปลี่ยนแปลงใด ๆ

**ข้อจำกัด**: ครอบคลุมเฉพาะการทุบด้วยผู้เล่นตามปกติ (BlockBreakEvent) — บล็อกที่ถูกทำลายด้วยระเบิดหรือวิธีอื่นจะดรอปเป็นไอเทมวานิลลาปกติและเสียระดับอัพเกรดไป

## ตั้งค่า (config.yml)
แต่ละเครื่องมี `display-name` (ชื่อที่แสดงในเมนู/ข้อความ/ไอเทมที่ดรอป), `max-level`, list อัตราตามระดับ, และ `price` (index 0 = ยังไม่อัพเกรด = ไม่มีราคา) ปรับได้อิสระ เช่น
```yaml
furnace:
  display-name: "เตาเผา"   # ชื่อที่แสดงในเมนู/ข้อความ/ไอเทมที่ดรอป - แก้เป็นข้อความอะไรก็ได้
  max-level: 4
  # index 0 = ยังไม่อัพเกรด (เผาทีละ 1 ชิ้นแบบวานิลลา), ระดับ 1-4 = 8/16/24/32
  smelt-batch-size: [1, 8, 16, 24, 32]
  price:
    money: [0, 500, 1500, 3000, 6000]   # ราคาเงินเพื่อ "ไปถึง" ระดับนั้น (ต้องมี Vault)
    item:
      material: IRON_INGOT              # ตั้งเป็น "" ถ้าไม่ต้องการเก็บราคาไอเทม
      amounts: [0, 8, 16, 32, 64]
```
- ตั้งได้ทั้งราคาเงินและไอเทมพร้อมกัน (ต้องจ่ายครบทั้งคู่ถ้าตั้งไว้ทั้งคู่) หรือเปิดแค่อย่างใดอย่างหนึ่งก็ได้ (ตั้งอีกอย่างเป็น 0 / material เป็น `""`)
- แก้ตัวเลขในไฟล์แล้วรัน `/upgrade reload` ใช้ได้ทันที ไม่ต้อง build ใหม่

## ข้อจำกัดที่ควรรู้
- **Dispenser / Dropper**: ไอเทมพิเศษที่ดันออกเพิ่ม จะถูก "ดรอปออกมาตรง ๆ" หน้าตัวบล็อก แทนที่จะเลียนแบบพฤติกรรมพิเศษของไอเทมนั้น ๆ ทุกอย่าง (เช่น ถังน้ำ/ไข่มอนสเตอร์/ลูกศร ของ Dispenser) ของชิ้นแรกยังทำงานแบบวานิลลาปกติ ส่วนชิ้นโบนัสจะออกมาเป็นไอเทมดรอปเฉย ๆ
- **Crafter**: เป็นบล็อกใหม่ (1.21+) API ของ Paper ยังไม่นิ่งเท่าตัวอื่น จึงใช้วิธี "คราฟซ้ำ" แทนการลด cooldown ภายในบล็อกโดยตรง ควรทดสอบกับเวอร์ชันเซิร์ฟเวอร์จริงก่อนใช้งานจริง
- **ราคาเงิน**: ต้องมี Vault + ปลั๊กอินระบบเงิน (เช่น EssentialsX) ติดตั้งอยู่ ไม่งั้นจะถูกข้ามอัตโนมัติ (ปลั๊กอินนี้ไม่ผูกกับปลั๊กอินระบบเงินเจาะจงตัวใดตัวหนึ่ง)
- ทดสอบบน **Purpur 26.2-stable** เป็นหลัก (compile ด้วย `paper-api:26.2.build.121-stable`, Java 25) โค้ดใช้แต่ API มาตรฐานที่ไม่เปลี่ยนระหว่าง 26.2 → 26.3-alpha จึงรองรับ Purpur 26.3 ล่วงหน้าได้ในทางเทคนิค แต่ควรทดสอบซ้ำบนเซิร์ฟ 26.3 จริงทันทีที่มี stable build ให้ใช้ (ดู HANDOFF.md)
